# List the covariance methods setCov() can compute

List the covariance methods setCov() can compute

## Usage

``` r
setCovAllMethods()
```

## Value

character vector of methods, including those registered by other
packages

## Examples

``` r
setCovAllMethods()
#> [1] "analytic" "imp"      "r"        "r,s"      "s"        "sa"      
```
